JARVIS 0.6.1 — local self-management preview

- Isolated source improvement jobs followed by separate review jobs.
- Check receipts tied to the unchanged source snapshot.
- Ordinary documentation merges after review; explicit owner approval for sensitive changes.
- Source history remains separate from the installed app; local mode does not publish to GitHub.
- Signed GitHub release discovery, artifact verification and approved Mac installation.
- App identity and the fixed credential vault are checked before installation.
- Failed launch checks stop the owned new app and restore the previous app.
- Fresh-checkout runtime assets and UUID-safe dependency license packaging.
- Public source export, DMG packaging and locally signed release candidate tools.

GitHub maintenance requires separate proposer/reviewer identities and enforced owner
review and CI rules. Release publication requires a separate exact-commit owner
approval; configuration alone does not publish a release.
The current Mac build uses a local certificate, not Apple notarization. Android updates use
normal Android installation approval. Five moderate development-packaging advisories
remain under review; this is an experimental test release.
